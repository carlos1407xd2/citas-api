# Arquitectura y fronteras

El backend objetivo usa Java 21, Spring Boot 3.5.x, Maven, arquitectura hexagonal, Spring Data JPA, Flyway, MySQL 8.4, Spring Security y JWT. El frontend será React o Angular según Stitch/AI Studio y no debe incorporar Express/BFF.

La wiki es global y la mantiene el orquestador; los agentes de repositorio no mantienen wikis paralelas.
