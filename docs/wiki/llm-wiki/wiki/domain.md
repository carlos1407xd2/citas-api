# Dominio y reglas

El dominio cubre usuarios, roles, profesionales, especialidades, sedes, disponibilidad, slots, citas, reprogramaciones, estados e historial. La autoridad de las reglas de reserva, autorización y transiciones es el backend.

Claims clave: slots consecutivos para 60 minutos; citas generales auto-aprobadas; citas especializadas y reprogramaciones sujetas a decisión administrativa; cancelación y rechazo liberan reservas; todo cambio de estado se audita.
