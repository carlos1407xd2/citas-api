# Workflows

## INGEST

Leer una fuente aprobada, crear un snapshot RAW nuevo, integrar sus claims en páginas WIKI, enlazar páginas relacionadas, actualizar el índice y añadir una entrada al log.

## QUERY

Leer índice → páginas relevantes → fuente/código de verificación. Separar evidencia de inferencia en la respuesta.

## LEARN

Extraer únicamente conocimiento durable, clasificarlo y verificarlo antes de persistirlo.

## LINT

Revisar contradicciones, obsolescencia, duplicados, huérfanas, links rotos, decisiones sin aprobación y material sensible.
